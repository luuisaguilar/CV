# CV rescue publication classification

Date: 2026-06-05

This folder contains rescued local portfolio planning artifacts, but not all content is ready for public homepage copy.

## Safe to publish now

- High-level positioning: operations, automation, portfolio differentiation.
- Generic project categories.
- UI/UX and content strategy notes.
- The preserved `enterprise-scene-prototype.tsx.txt` as a reference artifact, not app code.

## Requires review before publishing as marketing copy

- Any client/project names.
- Screenshots or case-study details.
- Metrics that could identify a client or engagement.
- Claims about active clients, revenue, salary, invoices, contracts or private work.

## Redactions applied in this branch

- Real client names in `portfolio-backlog-adr.md` were replaced with `[CLIENTE REDACTADO]`.

## Recommended next step

Before merging or using this content on the public CV site, convert the backlog into a public-safe case-study draft with:

1. Generic client labels, e.g. “food distribution business” instead of names.
2. No private screenshots unless explicitly approved.
3. No emails, phone numbers, credentials, webhook URLs, env values or internal documents.
4. Claims phrased as capabilities unless backed by public evidence.
